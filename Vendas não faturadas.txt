Com base na planilha enviada (abas **AÉREO**, **TERRESTRE** e consolidação de **Não Faturados**), segue um prompt completo para utilizar em ferramentas de IA de desenvolvimento (ChatGPT, Claude, Cursor, Windsurf, Lovable, Bolt, Replit AI, etc.) para gerar um sistema de BI operacional e gerencial profissional.

DESENVOLVA UM SISTEMA WEB DE BUSINESS INTELLIGENCE (BI) PARA GESTÃO DE VENDAS NÃO FATURADAS DO SETOR DE TURISMO CORPORATIVO, COM PADRÃO VISUAL EXECUTIVO E FINANCEIRO.

OBJETIVO:
Criar um portal web responsivo, moderno e profissional para acompanhamento operacional e gerencial de vendas não faturadas, integrando dados do ERP Benner através de conexão direta com banco de dados SQL.

TECNOLOGIAS SUGERIDAS:

* Frontend: HTML5, CSS3, Bootstrap 5, JavaScript, Chart.js, DataTables
* Backend: Node.js ou Python
* Banco de Dados: SQL Server, Oracle ou PostgreSQL
* Exportação: Excel (.xlsx), CSV e PDF
* Layout estilo Power BI, Tableau e dashboards financeiros corporativos.

PADRÃO VISUAL:

* Tema corporativo do segmento de turismo e viagens.
* Layout clean.
* Cards financeiros.
* Indicadores em tempo real.
* Menu lateral recolhível.
* Modo escuro e claro.
* Design executivo semelhante a sistemas financeiros ERP.
